# Bottom navigation icons

This directory contains 64 x 64 transparent PNG icons for the four primary
navigation tabs. Each tab has a gray linear default state and a blue duotone
active state.

The glyphs are adapted from the Solar icon set by 480 Design through Iconify
and are licensed under CC BY 4.0:
