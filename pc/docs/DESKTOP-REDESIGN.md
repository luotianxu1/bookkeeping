# 桌面页面重构

本次修改针对 PC 内的业务视图和交互编排，使用 Vue 3、TypeScript、Element Plus。页面按桌面工作流重排，1024px 和 1440px 窗口均可操作；表格必要时在内容面板内横向滚动，操作列固定在右侧。

## 页面编排

| 模块 | 页面范围 | 桌面布局 |
| --- | --- | --- |
| 权限管理 | 用户、角色、权限目录与授权 | 保留既有桌面表格、筛选和授权面板，执行真实 RBAC 回归 |
| 财务管理 | 财务总览、收支流水、记账、分析、预算、分类、退款报销、固定支出 | 总览指标和图表；流水筛选与单张分页明细；分析图表、分类与期间汇总；编辑分组表单 |
| 工资 | 工资总览、设置、记录、现金流、社保/公积金/医保、个税 | 汇总指标、缴纳明细、账户侧栏、年度与月度记录表、分组设置表单 |
| 资产管理 | 全部账户、现金、债权、负债、人情、黄金、投资、清仓、定期存款、储蓄目标 | 账户清单、指标与记录表、账户资料侧栏、页头和行内操作、桌面对话框 |
| 投资分析 | 资产趋势、投资详情、基金收益、红利策略、攒股收息、收益/回本/收息/财务自由预测、汇率 | 走势图、持仓和交易表、详情页签；参数面板与结果分栏 |
| 行情中心 | 全球、A股、港股、美股、ETF、黄金、基金、板块、标的详情、金价、快讯、选股 | 市场页签、报价表、涨跌分布与榜单；走势主区和报价侧栏；选股条件、结果与选中标的走势 |
| 生活工具 | 日历、纪念日、待办、联系人、摄影订单及总览、旅行、健康、体重 | 完整月/年日历、管理表格；订单图表；旅行地图、行程与费用页签；健康参数与结果、体重趋势与历史 |
| 家庭餐饮 | 点菜、菜品、菜谱录入/详情、菜单、食材和分类 | 菜品表与常驻选单侧栏；菜谱步骤和食材分栏；菜单明细表；分类与食材维护表单 |
| 账号与家庭 | 资料、安全、会话、家庭成员、提醒、图标、定时任务 | 资料与偏好分栏；安全设置与设备表；家庭成员与邀请侧栏；提醒、任务表；图标检索 |

注册、找回密码、登录与状态页沿用独立桌面认证表单。所有入口、详情及编辑路由见 [功能盘点](FEATURES.md)。

## 共享组件

- `PagePanel`：面板标题、操作与内容区。
- `MetricStrip`：紧凑的横向指标。
- `DesktopTable`：全量本地数据搜索、排序后分页；列使用 `sortable="custom"`。服务端分页页面传入 `paginate=false`，由页面保留远程查询和分页。
- `TransactionTable`：统一流水明细，展示日期、账户、分类、金额和备注；保留退款/报销、定期流水操作限制。
- `CashFlowChart`：近两周真实现金收支，按需加载图表模块并随容器调整大小。
- `desktop.css`：明确的桌面分栏、表格、表单、日历、行情、旅行和菜谱布局。

外层布局持续存在，菜单仅更新功能区。Element Plus 的按需样式提前优化，避免首次进入新路由时触发 Vite 依赖重优化和文档刷新。

## 验证范围

- `pnpm test`：12 项请求、会话、权限与路由测试。
- `pnpm build`：TypeScript 检查及生产构建。
- `pnpm test:e2e:business`：12 项浏览器测试；覆盖全部菜单的服务失败状态、外层布局保持、联系人增删改、记账字段、菜单创建、日历/预测/基金/体重图表、投资重试幂等字段、旅行费用保存、流水筛选和受保护记录、12 个有数据页面在 1024/1440 宽度下的布局、跨页搜索排序。
- `pnpm test:e2e:dev`：全新 Vite 缓存逐项访问全部菜单，检查文档请求、整页刷新消息、侧栏/顶栏实例和浏览器返回。
- `pnpm test:e2e:live`：生产认证/账务服务与隔离 H2；验证 Cookie 登录、记账、重试幂等、用户隔离、储蓄预留。
- `pnpm test:e2e`：生产认证/RBAC 服务与隔离 H2；验证用户、角色、授权、会话与权限保护。

业务浏览器测试使用可控响应，真实联通测试只覆盖上述认证、权限及账务流程。行情上游和地图服务仍依赖运行环境，本次没有访问开发数据库或调用外部行情与地图数据。
