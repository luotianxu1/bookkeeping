# Feature icons

The PNG files in this directory are 64 x 64 transparent exports used by
`FeatureIcon`. Their editable SVG sources are stored in `source/`.

The glyphs are adapted from the Solar icon set by 480 Design and Streamline's
Ultimate free icons through Iconify. Both sets are licensed under CC BY 4.0:

- https://www.figma.com/community/file/1166831539721848736
- https://github.com/webalys-hq/streamline-vectors
- https://creativecommons.org/licenses/by/4.0/
