# Account icons

The PNG files in this directory are 64 x 64 transparent account icons. Their
editable SVG sources are stored in `source/`. The account list selects a PNG
from the database `accounts.icon` value and falls back to the account type.

Most glyphs are adapted from the Solar icon set by 480 Design through Iconify.
The gold-bars glyph is adapted from Streamline's Ultimate free icons through
Iconify. Both sets are licensed under CC BY 4.0:

- https://www.figma.com/community/file/1166831539721848736
- https://github.com/webalys-hq/streamline-vectors
- https://creativecommons.org/licenses/by/4.0/

Bank marks are derived from the favicons published by each bank's official
website. Bank names and marks remain the property of their respective owners.
