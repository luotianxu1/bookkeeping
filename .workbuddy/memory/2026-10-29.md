## tool-service 启动失败排查

- 现象：`NoClassDefFoundError: AnniversaryRequest`（无包名）。
- 根因：IDEA 增量编译失败时把带 `Unresolved compilation problems` 的坏 class 写入 target/classes（Eclipse 编译器行为）；后续 `mvn compile` 增量判断 class 比 .java 新而跳过重编，坏产物残留。
- 修复：`mvn clean compile -DskipTests` 全量重建，grep 确认无残留坏 class。
- 教训：IDEA 与命令行 Maven 共用 target/classes 时，遇到 NoClassDefFoundError 先查 class 字节码里是否有 "Unresolved compilation problems"，有则 clean rebuild + IDEA Rebuild Project。
