## tool-service 启动失败排查

- 现象：`NoClassDefFoundError: AnniversaryRequest`（无包名）。
- 根因：IDEA 增量编译失败时把带 `Unresolved compilation problems` 的坏 class 写入 target/classes（Eclipse 编译器行为）；后续 `mvn compile` 增量判断 class 比 .java 新而跳过重编，坏产物残留。

## 接口慢排查（数据库+后端专项）
- 结论：数据库与后端服务均非瓶颈，慢在 Cloudflare Tunnel 链路层。
- 实测：本地 4173 静态页 204ms；Tunnel 外网 2.09s（TLS 1.27s + TTFB 2.09s），每个 API 请求多付 ~1.9s。
- 四服务进程都在运行（IDEA 调试模式），本地直连业务接口 401 仅 13-38ms。
- MySQL 5.7.39（AGENTS.md 写 8.0+ 不符）；数据量极小（transactions 300 行，最大表 stock_screen_snapshots 52MB 为选股定时任务产生）；索引设计完善；slow_query_log=OFF、long_query_time=10s（偏宽）。
- DB 密码在 .idea/runConfigurations 的 DB_PASSWORD 环境变量（memory 已有记录）；mysql 客户端路径 /opt/homebrew/opt/mysql@5.7/bin/mysql。
- 代码热点（当前数据量下影响小，数据涨后显现）：getAnalysis 全量加载三表进内存过滤；page() 每请求执行 3 次 3 表 UNION（count/sum/page）；投资接口同步外呼行情 API 超时 8-10s。
- 建议方向：API 不走 Tunnel（Nginx 直反代/国内可达直连）、行情外呼加缓存、开慢查询日志长期监控。
