## 修复：InvestmentService 编译错误（IDEA 抓到、mvn 假成功漏掉）
- 症状：IDEA 编译报 `'try' 不带有 'catch', 'finally' 或资源声明`；此前 mvn compile 却 BUILD SUCCESS——正是「mvn 增量编译假成功」坑（target/classes 有陈旧 .class 跳过 javac）。
- 原因1：并发化改造时 runInvestmentSyncCycle 丢了 finally 残留悬空 try（共享 Map 改显式局部变量后无需清理，直接去掉 try 包裹）。
- 原因2：漏 import java.util.concurrent.ConcurrentHashMap（java.util.* 不覆盖 concurrent 包），两处使用报「找不到符号」。
- 教训固化：改完 Java 源码后，先 `rm -f 对应 .class` 或 `mvn clean compile` 再信 BUILD SUCCESS；IDEA 编译结果与 mvn 不一致时以能过 clean compile 为准。
