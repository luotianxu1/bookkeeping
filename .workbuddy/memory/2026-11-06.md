# 2026-11-06 前后端优化

用户授权完成本轮审查的全部优化；改动保留在本地工作区，未提交、推送或部署。

- 账务事务共用用户行锁：普通记账、投资、账户变更、借还款、人情往来、负债、续费和摄影订单。现金增减用原子 SQL，修正同账户编辑先回滚再重算时丢失退款的问题。
